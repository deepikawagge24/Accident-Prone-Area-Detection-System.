# Accident Prone Area Detection System

## About the Project
The Accident Prone Area Detection System is a Python-based data analysis project that analyzes road accident data to identify accident-prone locations. It studies accident patterns based on time and visualizes high-risk areas using graphs and interactive maps.

## Features
- Road accident data analysis
- Identification of Top 10 accident-prone locations
- Accident time analysis
- Graphical data visualization
- Interactive accident location mapping

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Folium
- Jupyter Notebook

## Project Files
- `MINI PROJECT.ipynb` – Python code and data analysis.
- `accident_data.csv` – Road accident dataset.

## Objective
To identify accident-prone areas through data analysis and visualization, helping understand accident patterns and supporting road safety planning.
